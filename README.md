# 🛒 Ecommerce WordPress con Docker

Este proyecto monta un entorno de desarrollo completo para una tienda online basada en WordPress y WooCommerce, utilizando Docker y variables de entorno seguras.

---

## 🚀 Tecnologías usadas

- 🐳 Docker & Docker Compose
- 🗃️ MariaDB (Base de datos)
- 📰 WordPress (CMS)
- 🛍️ WooCommerce (Plugin de tienda online)

---

## 📦 Requisitos

- Docker
- Docker Compose
- Git
